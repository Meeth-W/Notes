# Topics Covered in Module 3

- **Requirements Fundamentals**: Understanding the distinctions and importance of Functional, Non-functional, and Domain requirements in software engineering.
- **Feasibility Studies**: Evaluating the technical, economic, and operational viability of a project to aid in critical "go/no-go" decision-making before committing heavy resources.
- **Requirement Lifecycle Management**: 
  - Identifying the origins of requirement changes (e.g., market trends, user feedback, technological advancements, regulatory updates).
  - Executing Requirement Elicitation (gathering needs directly from stakeholders via interviews, surveys, and observation).
  - Conducting Requirement Analysis (resolving conflicting needs and organizing gathered data into structured models).
  - Performing Requirement Validation (executing validity, consistency, completeness, and realism checks to ensure alignment with user goals).
- **Requirements Documentation**: Designing and constructing comprehensive Software Requirements Specification (SRS) documents with appropriate functional and non-functional boundaries.
- **System Modeling and Diagramming**:
  - Building Use Case Diagrams to model actor interactions with the system.
  - Designing Data Flow Diagrams (DFDs), specifically mastering Level 0 (Context Diagrams) and Level 1 breakdowns utilizing Processes, Data Stores, and External Entities.
- **Project Scheduling**: Creating visual scheduling diagrams (like Gantt charts) to effectively map parallel and dependent project phases (Requirements, Design, Implementation, Testing) over time.
- **Software Cost and Effort Estimation**:
  - **Function Point Analysis (FPA)**: Calculating system size using the five information domain characteristics (External Inputs, Outputs, Inquiries, Internal Logical Files, External Interface Files), and computing Unadjusted Function Points (UFP) alongside Value Adjustment Factors (VAF).
  - **COCOMO Models**: Understanding the conceptual differences between Basic, Intermediate, and Detailed models. Applying complex mathematical formulas across Organic, Semi-detached, and Embedded modes to calculate project Effort (in Person-Months), Development Time, Team Size Staffing, and Total Financial Cost.
